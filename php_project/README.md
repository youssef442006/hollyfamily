# نظام إدارة الكنيسة القبطية الأرثوذكسية (PHP & MySQL / XAMPP)

مشروع متكامل بنسبة 100% مبني بـ **PHP النقي (Native PHP)** وقاعدة بيانات **MySQL (XAMPP)** بدون الحاجة لأي خوادم خارجية مثل Python أو Node.js.

---

## 🚀 التشغيل المباشر

### الطريقة الأولى (بضغطة زر واحدة):
- اضغط مرتين على ملف **`start_church.bat`** في المجلد الرئيسي.
- سيقوم تلقائياً بتشغيل Apache و MySQL وفتح المتصفح على:
  **`http://localhost/church`**

### الطريقة الثانية (من لوحة XAMPP):
1. افتح **XAMPP Control Panel**.
2. اضغط **Start** لكل من **Apache** و **MySQL**.
3. افتح المتصفح على: **`http://localhost/church`**

## 🗄️ قاعدة البيانات (MySQL)
- اسم قاعدة البيانات: `church_management`
- ملف الاستيراد الكامل: `database.sql`
- الرابط في phpMyAdmin: `http://localhost/phpmyadmin`
- المستخدم الافتراضي: `root` (بدون كلمة مرور).

## 📁 الشاشات والمميزات المضمنة
1. **الرئيسية (index.php):** لوحة تحكم وإحصائيات، تنبيهات المتابعة والاعترافات، ومخطط المراحل السنية.
2. **سجل الأسر والعائلات (families.php):** إضافة، تعديل، حذف، بحث متقدم وعناوين.
3. **تفاصيل الأسرة (family-details.php):** شجرة الأسرة، الأفراد، سجل الافتقاد العائلي.
4. **معالج إضافة أسرة كاملة (family-wizard.php):** تسجيل العائلة والأب والأم والأولاد في خطوة واحدة.
5. **سجل المخدومين والشعب (persons.php):** قائمة المخدومين، فلترة المراحل، الخدام والشمامسة.
6. **الملف الشخصي الشامل (person-details.php):** ملف 360 درجة، سجل الاعترافات، الافتقادات، الواتساب والتليفون.
7. **قطاعات ومدارس الأحد (services.php):** فصول مدارس الأحد والاجتماعات وتوزيع الخدام.
8. **سجل الاعترافات (confessions.php):** متابعة سر الاعتراف، الآباء الكهنة، والتنبيه بالمتأخرين.
9. **سجل الافتقادات (visits.php):** زيارات منزلية، مكالمات، ومتابعة حالات الرعاية.
10. **كشف التكرار والدمج (duplicates.php):** كشف التكرارات بالرقم القومي أو التليفون أو الاسم مع دمج السجلات.
11. **التقارير والإحصائيات (reports.php):** كشوف قابلة للطباعة حسب المرحلة، الخدام، أعياد الميلاد.
12. **إعدادات النظام والمستخدمين (settings.php):** إدارة حسابات المستخدمين وصلاحياتهم، بيانات الكنيسة.
